What this page is

A bench for the cutout feature in CozyClay issue #17: drop a picture in, stand it up as a card, and block against it. It imports exactly two files from the studio — scene-objects.js for the record and its metric size, scene-assets.js for the import path — and brings its own viewer, so the sizing you see is the model's behaviour, not the app's.

Why height, not scale

Every camera level in CozyClay is a height in metres — eye level is 1.5 m, hip 0.95 m — and framing is measured against a 1.80 m figure. So a card is sized by typing what it really is: the width follows from the picture's own aspect and is never entered by hand.

Why the id is a hash

The picture is addressed by a digest of its own bytes, so importing the same photo twice stores it once and a duplicated scene shares the original. Import a sample twice and watch the asset count hold still.

What is still missing

Matting a photo that has no alpha, the outline pass learning to ink a silhouette instead of a rectangle, a grabbable footprint on the plan board, and billboard facing. Those are the rest of the issue.
