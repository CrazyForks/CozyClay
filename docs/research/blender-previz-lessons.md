# Blender에서 배울 것 — 프리비즈 관점 심층 리서치 (v2, 전면 재조사)

> 2026-08-30 재작성. 출처: blender/blender GitHub 미러 실측 + 공식 매뉴얼(5.x) +
> developer.blender.org 트래커 + Blender Studio 파이프라인 문서.
> CozyClay는 독자 소프트웨어 — 아이디어 참조 스케치이며 코드 이식 없음.
> 표기: [P0] 즉시 구현 대상 / [P1] 다음 사이클 / [P2] 장기. 각 항목에
> Blender 동작 원리 → CozyClay 이식 설계 → 테스트 포인트를 적는다.

---

## A. 컷 · 샷 시스템

### 1. [P0] 타임라인 마커 + 카메라 바인딩 (Bind Camera to Markers)
- Blender: 마커는 정수 프레임에만 놓이는 네임드 포인트. 카메라를 선택하고
  마커에 바인딩(Ctrl+B)하면 재생/스크럽 중 그 프레임부터 다음 바인딩 마커
  전까지 해당 카메라가 활성 카메라가 된다. 마커는 타임라인/돕시트/그래프/
  시퀀서 전 에디터에서 공유 표시된다(단일 데이터 소스).
- 이식 설계: CozyClay 샷(카메라 셋업)에 `cutFrame`(정수)을 부여하고 타임라인에
  컷 트랙을 추가. 재생 헤드가 컷 프레임을 지나면 PlayView 카메라가 해당 샷
  카메라로 전환. 컷 블록은 다음 컷 전까지의 구간을 색 밴드로 표시.
- 테스트: 컷 2개 배치 → 스크럽 시 활성 카메라 전환 프레임 정확성, 컷 삭제 시
  이전 컷으로 복귀, 저장/로드 왕복.

### 2. [P1] 마커 유틸리티 관례
- 마커 이름 변경(Ctrl+M), 복제 시 이름 무변경(.001 카운터 없음), 마커 행에서
  박스 선택. 커뮤니티는 마커를 JSON으로 임포트/익스포트해 타 소프트웨어와
  교환한다 — CozyClay 컷 트랙도 씬 JSON에 평문 배열로.

### 3. [P2] 프리뷰 레인지
- 특정 구간만 반복 재생(P로 드래그 지정, Alt+P 해제; VSE에서도 동일). 샷 하나를
  루프 돌리며 다듬는 프리비즈 기본기. CozyClay: 컷 블록 더블클릭 = 그 구간 루프.

## B. 카메라 리그

### 4. [P0→P1] Dolly / Crane 리그 프리셋 (동봉 Add Camera Rigs의 설계)
- Blender: 원클릭 생성, 루트(이동)/에임(시선)/카메라(오프셋) 분리 본 구조.
  Crane은 Arm Height·Arm Length 두 개의 애니 가능 슬라이더만 추가 노출.
  리그가 선택되면 사이드바에 카메라 속성이 표시되고, "Make Camera Active"
  버튼과 "Add Marker and Bind"(컷과 리그의 접점!) 버튼 제공.
- 이식 설계: CozyClay 카메라 무브를 "root 경로 + aim 타깃 + (크레인이면
  armHeight/armLength)" 파라미터 셋으로 재구성. 프리셋 버튼 Dolly/Crane.
- 테스트: 크레인 파라미터 키프레임 보간, 리그 삭제 시 카메라 독립 유지.

### 5. [P1] 2D 리그의 코너 프레이밍 (역발상의 백미)
- 프레임 좌우 코너 두 개를 고정하면 카메라가 움직여도 focal/rotation/shift를
  자동 보정해 프레이밍 유지 — 코너를 피사체 양옆에 두고 카메라를 전진시키면
  달리줌이 자동으로 나온다. Rotation 모드(회전 보정)와 Shift 모드(렌즈 시프트
  크롭) 및 중간 블렌드 제공.
- 교훈: "카메라를 조작"이 아니라 "프레이밍을 고정하고 카메라가 따라오게".

## C. 카메라 프레이밍 보조

### 6. [P0] 컴포지션 가이드 8종
- 카메라 뷰 오버레이: 삼분할, 이등분(Center), 대각선, 골든 레이쇼(0.618 분할),
  골든 트라이앵글 A/B, 하모니 등 8종. 구현 난도 최하·체감 최상.
- 이식: SHOT 카드 + PlayView에 가이드 드롭다운(없음/삼분할/골든/센터).
- 테스트: 종횡비 변경(16:9↔9:16) 시 가이드 라인 위치 재계산.

### 7. [P0] 파스파르투(passepartout)
- 카메라 프레임 밖을 반투명 어둡게(알파 조절 가능). 프레임 안/밖이 즉시 읽힘.
- 이식: 뷰포트에서 샷 카메라 시점일 때 프레임 밖 마스킹.

### 8. [P1] 세이프 에어리어 + 센터컷
- 액션 세이프(90%)/타이틀 세이프(80%) + 다른 종횡비 대비 센터컷 영역
  (16:9 안의 4:3 등, 시안/블루 라인). 숏폼 동시 납품 시 16:9 안에 9:16
  센터컷을 그리는 식으로 그대로 유효.

### 9. [P1] 렌즈 실무 파라미터
- 카메라 shift(수직선 왜곡 없는 구도 조정), DOF 포커스 오브젝트(피사체 추적
  초점), 센서 크기. 최근 Blender는 오버레이 팝오버에 "카메라 가이드 일괄
  토글" 단일 체크박스를 추가 — 가이드가 늘면 마스터 스위치가 필요하다는 교훈.

## D. 플레이블라스트 · 리뷰 루프

### 10. [P0] 뷰포트 렌더 애니메이션 (플레이블라스트)
- 최종 렌더가 아니라 뷰포트 셰이딩 그대로를 실속도 영상으로 추출. 커뮤니티
  애드온들은 오버레이 숨김/오디오 포함/해상도 %/프레임 범위/자동 파일명까지
  원버튼화. Blender Studio는 샷별 플레이블라스트를 태스크 타입(Anim/Layout)
  별로 관리하고 편집 파일에서 Metadata Strip 기준으로 자동 갱신-임포트한다.
- 이식: CozyClay "Export Playblast" — PlayView 캔버스를 프레임 시퀀스로 캡처해
  webm/mp4 인코딩(MediaRecorder 또는 프레임 캡처+무비 엔코더).

### 11. [P0] 메타데이터 번인(슬레이트/스탬프)
- 렌더에 텍스트 스탬프: 날짜, 씬 타임코드(HH:MM:SS.FF), 프레임 번호, 카메라
  이름, 렌즈값, 씬 이름, **마지막 마커 이름**(=현재 샷!), 자유 노트. 글자
  크기/전경/배경색 조절, 라벨 표시 옵션.
- 이식: 플레이블라스트에 하단 번인 바 — 프로젝트/씬/샷(컷 이름)/프레임/렌즈.
- 테스트: 번인 텍스트가 캡처 프레임에 실제로 래스터라이즈되는지 픽셀 검사.

## E. 스토리보드 레이어 (Grease Pencil 생태계)

### 12. [P1] 뷰포트 주석(Annotation)
- 3D 공간/화면에 펜 스트로크 메모. 리뷰 코멘트를 샷 위에 직접 남긴다.

### 13. [P1] Storypencil의 왕복 편집 패턴
- 편집 타임라인(시퀀서)이 마스터, 씬이 소스. 씬 스트립에서 소스 씬의 같은
  시간 위치로 점프-편집-복귀(Back 버튼). 편집본 오디오를 소스 씬에 임시
  복사해 싱크 유지. 멀티샷 프리비즈의 정석 구조.
- 이식: CozyClay 멀티 씬에서 "에디트 뷰"(씬 스트립 나열) ↔ 씬 편집 왕복.

### 14. [P2] 스토리보드=애니매틱 단일 데이터
- 패널(그림)마다 직교 카메라를 만들어 마커에 바인딩 — 전체 패널을 한눈에
  보는 보드 뷰와 카메라 뷰의 애니매틱이 같은 데이터. 컷아웃+컷 트랙으로 재현
  가능.

## F. 뷰포트 셰이딩 · 오버레이 (Workbench 엔진)

### 15. [완료] 랜덤 오브젝트 컬러 → Auto Color로 이식 완료 (hue만 랜덤, 플랫 응답).

### 16. [P1] 캐비티 (ridge/valley 강조)
- 솔리드 모드 전용 스크린스페이스 효과. World(정밀·저속)/Screen(고속)/Both
  방식 선택, Ridge·Valley 강도 각각 조절. 회색 블록아웃에서 형태 가독성 급상승.
- 이식: CozyClay NPR 파이프라인에 스크린스페이스 캐비티 패스 + 강도 슬라이더.

### 17. [P1] 오브젝트 아웃라인 + X-Ray
- 아웃라인: 오브젝트 둘레 라인, 색 조절 가능, 토글. X-Ray: 가려진 오브젝트를
  보고 선택 — 투명도 슬라이더로 정도 조절. 복잡한 세트 블로킹에서 체감 큼.

### 18. [P2] 매트캡 + 스튜디오 라이트
- 씬 라이팅 무시하고 뷰 고정 재질/가상 라이트로 형태만 검토. 배경도
  테마/월드/커스텀 색 선택 — 뷰 검토 조건을 씬과 분리하는 사상.

### 19. [아키텍처] draw 엔진 분리 (미러 레포 실측)
- `source/blender/draw/engines/` = workbench / eevee / overlay / gpencil /
  compositor / select 분리. "씬 렌더"와 "오버레이/선택/주석 렌더"가 독립 엔진.
  CozyClay도 기즈모·가이드·번인을 씬 패스와 분리된 레이어로 유지.

## G. 내비게이션 (space_view3d 실측: navigate_fly/walk/smoothview/…)

### 20. [P1] SmoothView 원칙
- `view3d_navigate_smoothview.cc`: 넘패드 뷰 점프, 프레이밍, 카메라 진입 등
  모든 뷰 전환이 스냅이 아닌 짧은 보간. 공간 감각 유지의 핵심.

### 21. [P1] 프레이밍·축 뷰 계열
- `view3d_navigate_view_all/axis/center_pick/dolly.cc`: F(선택 프레임),
  Home(전체 프레임), 정면/측면/평면 축 점프, 픽 지점 센터링. CozyClay는 F만
  있음 — Home과 축 뷰가 공백.

### 22. [P1] Walk 모드의 디테일 (프리비즈 카메라 연기의 보물)
- Tab으로 중력↔자유 전환, V 점프, Spacebar 텔레포트(조준점의 표면으로 이동,
  카메라 높이 오프셋 유지), 휠로 이동 속도 조절, Shift/Alt 순간 가감속.
- **카메라 뷰에서 발동하면 활성 카메라가 같이 움직인다** — 그리고 오토키 +
  재생 중 Walk를 켜면 걸은 경로가 그대로 카메라 키프레임으로 녹화된다
  (= 게임패드식 라이브 카메라 캡처). CozyClay의 Walk 모드에 "레코드" 토글로
  이식하면 핸드헬드 무브가 공짜.

### 23. [P2] Lock Camera to View
- 카메라 뷰 안에서 뷰포트 내비가 곧 카메라 이동이 되는 토글. "보면서 찍기".

## H. 블로킹 애니메이션 도구

### 24. [P1] 모션 패스
- 선택 본/오브젝트의 궤적을 뷰포트에 표시. 키프레임은 노란 사각 점, 키 번호
  표시 옵션, 포즈 편집 시 자동 갱신, Around Current Frame 모드는 재생 중에도
  현재 프레임 기준 슬라이딩. CozyClay: 캐릭터 루트/waypoint 궤적 시각화.

### 25. [P1] 오토 키잉 + 브레이크다우너
- 오토키: 변형 즉시 키 삽입(토글). 브레이크다우너(Shift+E): 앞뒤 포즈 사이
  비율 보간 포즈를 마우스 드래그로 생성. 블로킹→스플라인 전환 핵심 도구.

### 26. [P2] 어니언 스킨
- 앞뒤 프레임 고스트. 커뮤니티 표준: past/future 개별 토글, 프레임 스텝,
  불투명 폴오프(선형/스무스/지수), 키프레임만 표시 모드(블로킹용).

### 27. [P2] NLA식 액션 스트립
- 액션(걷기/앉기)을 스트립으로 쌓아 반복/블렌드. Kimodo 테이크의 재사용 구조.

## I. 에디토리얼 (VSE)

### 28. [P1] 씬 스트립 = 라이브 에디트
- 씬을 시퀀서에 스트립으로 넣고 뷰포트 프리뷰로 라이브 편집 — 렌더 없이
  편집 타임라인에서 샷 씬을 직접 참조. 자기 씬은 스트립으로 못 넣는다
  (마스터 편집 씬을 분리하라는 구조적 강제). 5.3에선 씬 스트립 썸네일과
  드래그드롭 추가까지. 대형 프로젝트는 라이브가 느려져 프록시(플레이블라스트
  캐시)로 스왑하는 패턴이 정석 — D-14 항목과 연결.
- 이식: CozyClay "Edit" 탭 — 씬 스트립 나열 + 샷별 플레이블라스트 캐시 재생.

## J. 씬 조직 · 자산

### 29. [P1] 컬렉션 + 인스턴싱: 집합 기반 조직, 링크드 복제(수정 전파)로 군중/
  소품 세트. CozyClay Props 계층에 "그룹 인스턴스" 개념.
### 30. [P1] 애셋 브라우저 + 포즈 라이브러리: 썸네일 드래그드롭, 카탈로그 계층.
  씬 애셋조차 Add 메뉴에 카탈로그 구조로 노출된다. CozyClay 카탈로그의 확장

### 31. [P2] 라이브러리 링크/오버라이드: 씬 간 캐릭터 공유 + 로컬 오버라이드.
