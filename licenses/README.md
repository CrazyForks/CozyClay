# Third-party licence texts

Verbatim licence files for the components CozyClay redistributes in a build.
`THIRD_PARTY_NOTICES.md` at the repository root explains what each one covers;
this directory exists so the texts themselves ship with the code, which Apache-2.0
and MIT both ask for.

| File | Component | Licence |
| --- | --- | --- |
| `three.js-LICENSE.txt` | three.js | MIT |
| `react-LICENSE.txt` | React, React DOM | MIT |
| `react-three-fiber-LICENSE.txt` | @react-three/fiber | MIT |
| `react-three-drei-LICENSE.txt` | @react-three/drei | MIT |
| `draco-LICENSE.txt` | Draco decoder (`dist/assets/draco_*`) | Apache-2.0 |
| `basis-universal-LICENSE.txt` | Basis transcoder (`dist/assets/basis_transcoder*`) | Apache-2.0 |

Font licences live next to the fonts in `public/fonts/`, so they follow the
build into `dist/fonts/` rather than being left behind in the repository.
