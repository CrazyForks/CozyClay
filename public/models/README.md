# CozyClay CC0 mannequins

The male and female FBX files in this directory are generated from Blender
Foundation Human Base Meshes v1.4.1, released under CC0 1.0 Universal.

- Source and licence: https://www.blender.org/download/demo-files/
- Archive: https://download.blender.org/demo/asset-bundles/human-base-meshes/human-base-meshes-bundle-v1.4.1.zip
- Archive SHA-256: `811f43accbb31a88266d932f8f5563b2d13586fca0ba2693aad1f5fe582b3515`
- Builder: `tools/models/build-cc0-mannequins.py`

The generated armature, skin weights and smooth faceless mannequin treatment
are CozyClay project work. The source neutral stance is preserved, and both
models share one 27-joint contract.
